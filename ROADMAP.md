# 🗺️ Дорожная карта проекта Crew Booking Platform (Roadmap)

Платформа подбора и бронирования съемочного и технического персонала (кинооператоры, гаферы, звукорежиссеры, риггеры, гримеры, DIT-инженеры и продюсеры).

---

## ✅ ФАЗА 1: Выполнено в проекте (Released v1.0)

### 1. Единая классификация и база данных
- [x] Разработан SQL-скрипт схемы БД для Supabase / PostgreSQL (`supabase/schema.sql`) со всеми таблицами, перечислениями, RLS-политиками и сид-данными.
- [x] Создан полный классификатор **9 съемочных и технических цехов** (более 60 профессий) в `data/departments.json`.

### 2. Пользовательский веб-интерфейс (Frontend)
- [x] Реализована премиальная темная эстетика (Dark Mode `zinc-950`, `zinc-900`) с акцентами Cyan, Emerald и Amber.
- [x] Разработана мощная система мульти-фильтрации:
  - Живой поиск по имени, должности и тегам оборудования (`grandMA2`, `Midas M32`, `Blackout`, `Accsoon` и др.).
  - Древовидный селектор Цех -> Профессия.
  - Слайдер диапазона ставки за смену (10k - 100k+ ₽).
  - Флаг-бейдж `🎨 Готов к творчеству / TFP`.
  - Фильтр опыта в годах и наличии видео-шоурила.
  - Фильтр свободной даты съемок.
- [x] Реализовано переключение вида каталога: **Сетка карточек (Grid View)** / **Таблица (List View)**.

### 3. Профиль специалиста и Медиа
- [x] Полноэкранное модальное окно профиля специалиста с 4 вкладками (*О себе*, *Медиа (встраиваемый YouTube/Vimeo плеер + Галерея)*, *Опыт & Оборудование*, *Календарь занятости*).

### 4. Мобильная адаптация (Mobile UX)
- [x] Нижняя фиксированная навигационная панель (Bottom Nav Bar) для смартфонов.
- [x] Всплывающая мобильная шторка фильтров (Filter Drawer).
- [x] Мобильное модальное окно профиля (Bottom Sheet) с горизонтальной прокруткой вкладок.

### 5. Личные Кабинеты (2 типа ролей)
- [x] **Личный Кабинет Соискателя (Специалиста)**: формы редактирования био, ставки за смену, флага TFP, тегов оборудования, ссылок на шоурил и **интерактивного календаря** с кликабельным изменением занятости в 1 клик.
- [x] **Личный Кабинет Нанимателя (Продюсера / Компании)**: создание проектов/вакансий и мониторинг бронирований.

### 6. Администрирование и Хостинг
- [x] **Изолированная Админ-панель (`admin/index.html`)**: полная защита от обычных пользователей, вынос на поддомен (`admin.crewbooking.com`). Модерация кастомных профессий (`custom_subcategories`).
- [x] Автоматическое развертывание и хостинг на **GitHub Pages** (`https://schoolghga-dotcom.github.io/Crew-booking/`).

## 🚀 ФАЗА 2: В планах на ближайшую реализацию (Next Up)

- [ ] Подключение авторизации через Telegram / Google / Email в Supabase Auth.
- [ ] Перевод хранения профилей, проектов и отзывов из JSON в Supabase Database realtime API.

- [ ] Бот-ассистент для специалистов: мгновенные PUSH-уведомления в Telegram о новых предложениях съемок и запросах бронирования.
- [ ] Быстрый ответ кнопками в Telegram: `[Принять смену]`, `[Отклонить]`.

### 3. Система рейтингов, отзывов и проверок (Verified Crew)
- [ ] Модуль отзывов от продюсеров после завершения съемок с 5-звездочной шкалой.
- [ ] Бейдж **`Verified Specialist`** (Проверенный специалист) после загрузки дипломов, удостоверений или подтверждения от 3 зарегистрированных продюсеров.
