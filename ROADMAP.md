# 🗺️ Дорожная карта проекта Crew Booking Platform (Roadmap)

Платформа подбора и бронирования съемочного и технического персонала (кинооператоры, гаферы, звукорежиссеры, риггеры, гримеры, DIT-инженеры и продюсеры).

---

## ✅ ФАЗА 1: Выполнено в проекте (v1.2 Released)

### 1. Единая классификация и Схема БД
- [x] Написан SQL-скрипт схемы БД для Supabase / PostgreSQL (`supabase/schema.sql`) со всеми таблицами, RLS-политиками и сид-данными.
- [x] Наполнен базовый классификатор **9 съемочных и технических цехов** (`data/departments.json`).
- [x] Создана база из **12 реалистичных профилей специалистов** по всем 9 цехам (`data/specialists.json`).

### 2. Пользовательский веб-интерфейс (Frontend)
- [x] Темная премиальная палитра (Dark Mode `zinc-950`, `zinc-900`) с гибкой версткой под десктоп и смартфоны.
- [x] Мульти-фильтрация:
  - Текстовый поиск по имени, профессии и тегам оборудования (`grandMA2`, `Midas M32`, `Blackout`, `Accsoon`, `SmallRig`).
  - Древовидный селектор Цех -> Профессия.
  - Слайдер ставки за смену (10k - 100k+ ₽).
  - Флаг-бейдж `🎨 Готов к творчеству / TFP`.
  - Минимальный опыт и наличие видео-шоурила.
  - Фильтр свободной даты съемок.
- [x] Переключатель видов каталога: **Сетка карточек (Grid View)** / **Таблица (List View)**.

### 3. Личные Кабинеты (2 типа ролей)
- [x] **Кабинет Специалиста**: редактирование био, ставки за смену, флага TFP, тегов оборудования, видео-шоурила и **интерактивного графического календаря занятости** (клик переключает день Свободен/Занят).
- [x] **Кабинет Нанимателя (Продюсера)**: модальное окно «Новый съемочный проект» с **мультиселектом специальностей по цехам (чекбоксы)**, публикация съемок и мониторинг бронирований.

### 4. Мобильная адаптация (Mobile UX)
- [x] Нижняя навигационная панель (Bottom Nav Bar) для смартфонов.
- [x] Всплывающая мобильная шторка фильтров (Filter Drawer).
- [x] Полная защита от горизонтального разрыва верстки (`overflow-x-hidden`, `break-word-custom`, `truncate`).

### 5. Администрирование и Хостинг
- [x] **Изолированная Админ-панель (`admin/index.html`)**: полная защита от обычных пользователей, вынос на поддомен (`admin.crewbooking.com`). Модерация `custom_subcategories`.
- [x] Автоматическое развертывание на **GitHub Pages** (`https://schoolghga-dotcom.github.io/Crew-booking/`).
