# 📄 CONTEXT.md — Полный контекст проекта Crew Booking Platform

Данный файл содержит исчерпывающее техническое и функциональное описание проекта **Crew Booking Platform** для бесшовной передачи контекста другой языковой модели (LLM), разработчикам или заказчику.

---

## 🎯 1. Назначение и Бизнес-логика

**Crew Booking Platform** — специализированная веб-платформа для подбора, поиска и бронирования съемочного и технического персонала (кинооператоры, гаферы, звукорежиссеры, риггеры, гримеры, DIT-инженеры, художники-постановщики и продюсеры).

### Ключевые возможности:
- Единый классификатор из **9 съемочных цехов** и 60+ квалифицированных профессий.
- Мгновенная фильтрация по названию, цехам, тегам оборудования (`grandMA2`, `Midas M32`, `Blackout`, `Accsoon`, `SmallRig`), ставке за 12ч смену (руб.), флагу `🎨 Готов к творчеству / TFP` и графику свободных дат.
- Два типа личных кабинетов: **Кабинет Соискателя (Специалиста)** и **Кабинет Нанимателя (Продюсера / Кинокомпании)**.
- Интерактивное управление графиком свободных/занятых дней в календаре.
- Изолированная панель администрирования (`admin/index.html`), готовая к размещению на отдельном поддомене.

## 🛠️ 2. Технический стек и Архитектура

- **Frontend**: Vanilla HTML5, JavaScript ES6+, Tailwind CSS (через CDN), Lucide Icons, Google Fonts (Inter & JetBrains Mono).
- **Стилизация**: Deep Dark Mode (`zinc-950`, `zinc-900`, `slate-900`), неоновые акценты (Cyan `#06b6d4`, Emerald `#10b981`, Amber `#f59e0b`).
- **Мобильный UX**: Поддержка тач-событий, нижняя навигация (Bottom Nav Bar), мобильная шторка фильтров (Filter Drawer), выравнивание текста без горизонтальной прокрутки (`overflow-x-hidden`, `truncate`, `break-word-custom`).
- **Бэкенд / БД (Готовность)**:
  - `supabase/schema.sql`: Готовый SQL-скрипт PostgreSQL/Supabase со всеми таблицами (`profiles`, `departments`, `subcategories`, `custom_subcategories`, `availability`, `projects`, `bookings`, `reviews`), RLS-политиками и триггерами.
  - `data/departments.json`: Классификатор цехов и профессий.
  - `data/specialists.json`: 12 реалистичных профилей специалистов по всем 9 цехам.
- **Хостинг**: Проект опубликован и автоматически деплоится на **GitHub Pages** из ветки `main`.
  - URL сайта: `https://schoolghga-dotcom.github.io/Crew-booking/`
  - URL репозитория: `https://github.com/schoolghga-dotcom/Crew-booking`

## ⚙️ 4. Важные функции и реализация в коде

### А. Мультиселект специальностей при создании проекта (`app.js` & `index.html`)
- При создании съемочного проекта работодателем используется элемент `project-roles-panel` с поисковой строкой `roles-dropdown-search` и списком чекбоксов `roles-checkboxes-container`.
- Функция `toggleRolesListSection()` плавно открывает/скрывает панель выбора специальностей.
- Выбранные профессии отображаются янтарными тегами с крестиком удаления (`toggleRoleSelection(prof)`).

### Б. Интерактивный календарь соискателя (`renderInteractiveSpecCalendar()`)
- В Кабинете Специалиста выводится числовая сетка месяца (Август 2026).
- Функция `toggleMyDateAvailability(dateStr)` меняет статус кликнутого дня между «Свободен» (зеленый) и «Занят» (красный).

### В. Вынос Админки на Поддомен
- Из `index.html` и мобильного навбара полностью удалены все элементы администрирования.
- Файл `admin/index.html` — автономный интерфейс для модерации `custom_subcategories` (`is_approved`), который размещается на поддомене `admin.crewbooking.com`.

## 📝 5. Инструкции для следующей модели (LLM Prompt Guidance)

При продолжении разработки платформы рекомендуются следующие шаги:
1. **Интеграция Supabase**: Подключить `@supabase/supabase-js` клиент в `app.js` и заменить локальный `specialists.json` на запросы `supabase.from('profiles').select()`.
2. **Telegram Bot WebApp**: Сделать интеграцию с Telegram Bot API для отправки instant-уведомлений о бронированиях.
3. **Сохранять стиль**: Все новые компоненты должны придерживаться дизайна **Dark Mode** (`zinc-950`, `zinc-900`) с аккуратной версткой для смартфонов.
