# 🎬 Crew Booking Platform

Современная платформа для поиска, подбора и бронирования съемочного и технического персонала (кинооператоры, гаферы, звукорежиссеры, риггеры, гримеры, DIT-инженеры и продюсеры).

---

## 🔑 Личные Кабинеты (2 типа пользователей)

Платформа разграничивает роли нанимателей и соискателей:

1. **Кабинет Соискателя (Специалиста)**:
   - Редактирование профиля, выбор основного цеха и подкатегорий.
   - Финансовые условия: Настройка ставки за 12ч смену + Чекбокс `🎨 Готов к творчеству / TFP`.
   - Загрузка видео-шоурила (YouTube/Vimeo) и тегов оборудования (`grandMA2`, `Midas M32`, `Blackout`, `Accsoon`, `SmallRig`).
   - **Интерактивный календарь занятости**: Клик по числовой сетке моментально переключает статус дня ("Свободен" / "Занят на съемке").

2. **Кабинет Нанимателя (Продюсера / Компании)**:
   - Профиль кинокомпании/продакшена.
   - Создание проектов и публикация съемочных вакансий.
   - Мониторинг отправленных бронирований со статусами (`В работе`, `Сбор смены`, `Подтверждено`).

---

## 🛡️ Панель администрирования (Отдельный поддомен /admin)

В соответствии с правилами безопасности, панель администрирования полностью убрана из открытого интерфейса общего сайта `index.html`.

- **Страница Админки**: `admin/index.html`
- Предназначена для размещения на отдельном поддомене (например: `admin.crewbooking.com` или защищенном URL `/admin/`).
- Содержит модерацию заявленных подкатегорий (`custom_subcategories`), принятие/отклонение новых профессий в общий каталог и статистику системы.

---

## 🚀 Развертывание на GitHub Pages

Сайт готов к публикации на **GitHub Pages** в 1 клик:

1. Откройте репозиторий: `https://github.com/schoolghga-dotcom/Crew-booking`
2. Перейдите в **Settings -> Pages**.
3. В **Build and deployment -> Source** выберите **`Deploy from a branch`**.
4. Укажите ветку **`main`** и папку **`/ (root)`**, затем нажмите **Save**.
5. Сайт будет доступен по адресу:
   👉 **`https://schoolghga-dotcom.github.io/Crew-booking/`**

## 📁 Структура проекта

- `index.html` — Главный интерфейс публичного сайта с личными кабинетами соискателей и нанимателей (Dark Mode `zinc-950`).
- `admin/index.html` — Изолированная панель администрирования для поддомена.
- `app.js` — Движок работы с фильтрами, личными кабинетами и интерактивным календарем.
- `data/departments.json` — Классификатор 9 цехов и входящих профессий.
- `data/specialists.json` — Демо-данные профилей.
- `supabase/schema.sql` — Полная схема PostgreSQL/Supabase (таблицы, RLS политики, триггеры, сид-данные).
