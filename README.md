# 🎬 Crew Booking Platform

Современная веб-платформа для поиска и бронирования съемочного и технического персонала (кинооператоры, гаферы, звукорежиссеры, риггеры, гримеры, DIT-инженеры и продюсеры).

---

## ⚡ Развертывание на GitHub Pages (Захостить сайт за 1 минуту)

Сайт полностью подготовлен к публикации на **GitHub Pages** напрямую из репозитория:

1. Зайдите в ваш репозиторий на GitHub: `https://github.com/schoolghga-dotcom/Crew-booking`
2. Нажмите на вкладку **Settings** (Настройки репозитория).
3. В левом меню выберите пункт **Pages**.
4. В разделе **Build and deployment -> Source** выберите **Deploy from a branch**.
5. Выберите ветку `main` (или `master`) и папку `/ (root)`, затем нажмите **Save**.
6. Через 1-2 минуты ваш сайт будет доступен по ссылке:
   `https://schoolghga-dotcom.github.io/Crew-booking/`

## 🛠️ Структура проекта

- `index.html` — Главный UI платформы (Dark Mode `zinc-950`, фильтры по 9 цехам, модальное окно с YouTube/Vimeo шоурилом, галереей и календарем занятости).
- `app.js` — Движок работы с данными, древовидные фильтры, динамические специальности, админ-панель модерации.
- `data/departments.json` — Классификатор 9 цехов и всех профессий (Операторский, Света, Звука, Продюсерский, Режиссерский, Арт, Костюм/Грим, Грип/Риггинг, Пост-продакшен).
- `data/specialists.json` — Реалистичные профили специалистов с тегами оборудования (`grandMA2`, `Midas M32`, `Blackout`, `Accsoon`), бейджем `🎨 Готов к творчеству / TFP` и графиком дней.
- `supabase/schema.sql` — Полная готовность бэкенда! SQL-скрипт схемы таблиц PostgreSQL/Supabase (users, profiles, custom_subcategories, bookings, reviews, RLS политики).

## 🚀 Просмотр локально

Вы можете запустить встроенный веб-сервер Python для локальной проверки сайта:
```bash
python3 -m http.server 8000
```
И откройте в браузере `http://localhost:8000`.
