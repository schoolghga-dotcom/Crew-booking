# 🎬 Crew Booking Platform

Современная веб-платформа для подбора, поиска и бронирования кино- и технического персонала (кинооператоры, гаферы, звукорежиссеры, риггеры, гримеры, DIT-инженеры, художники-постановщики и продюсеры).

📌 **[Контекст для ИИ / Передачи в разработку (CONTEXT.md)](./CONTEXT.md)**

## 🚀 Деплой на GitHub Pages

Сайт полностью подготовлен к автономной публикации на **GitHub Pages**:

1. Откройте репозиторий: `https://github.com/schoolghga-dotcom/Crew-booking`
2. Перейдите в **Settings -> Pages**.
3. В **Build and deployment -> Source** выберите **`Deploy from a branch`**.
4. Укажите ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
5. Через 1 минуту сайт доступен по адресу:
   👉 **`https://schoolghga-dotcom.github.io/Crew-booking/`**

## 🔑 Личные Кабинеты (2 типа пользователей)

1. **Кабинет Соискателя (Специалиста)**:
   - Форма редактирования личных данных, аватара, стажа и образования.
   - Финансовые условия: Настройка ставки за 12ч смену + Чекбокс `🎨 Готов к творчеству / TFP`.
   - Загрузка видео-шоурила (YouTube/Vimeo) и тегов оборудования (`grandMA2`, `Midas M32`, `Blackout`, `Accsoon`, `SmallRig`).
   - **Интерактивный график занятости**: клик по числовой сетке месяца (Август 2026) переключает день между «Свободен» (зеленый) и «Занят» (красный).

2. **Кабинет Нанимателя (Продюсера / Компании)**:
   - Модальное окно **«Новый съемочный проект»** со встроенным **мультиселектом специальностей с чекбоксами по цехам** и быстрым поиском.
   - Публикация съемочных вакансий и формирование сменных команд.
   - Мониторинг отправленных бронирований и их статусов (`В работе`, `Сбор смены`, `Подтверждено`).

## 🛡️ Панель администрирования (Вынос на Поддомен)

- **Путь**: `admin/index.html` (изолированное приложение).
- Готово к публикации на отдельном поддомене (например `admin.crewbooking.com` или `/admin/`).
- Позволяет модерировать заявленные подкатегории (`custom_subcategories`), утверждать новые профессии в каталог и управлять пользователями.

## 📁 Структура файлов

- `index.html` — Главный интерфейс публичного приложения (Dark Mode `zinc-950`, фильтры по 9 цехам, профили, модальные окна, мобильная нижняя навигация).
- `admin/index.html` — Изолированная панель администрирования для поддомена.
- `app.js` — Движок веб-приложения (мультиселект чекбоксы, фильтрация, ЛК соискателя/работодателя, интерактивный календарь).
- `data/departments.json` — Классификатор 9 цехов и 60+ профессий.
- `data/specialists.json` — База данных 12 специалистов по всем 9 цехам.
- `supabase/schema.sql` — Полная схема PostgreSQL / Supabase с RLS-политиками.
- `ROADMAP.md` — Дорожная карта выполнения этапов.
- `CONTEXT.md` — Контекст проекта для передачи сторонним LLM и разработчикам.
